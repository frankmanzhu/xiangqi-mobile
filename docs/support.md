# Xiangqi support

Xiangqi Mobile is developed and maintained by Frank Zhu.

For support, [open an issue in the Xiangqi Mobile issue tracker](https://github.com/frankmanzhu/xiangqi-mobile/issues). Include your device model, iOS version, app version, what you were doing, and what you expected. GitHub issues are public; do not include private information. A GitHub account is required to submit an issue.

## Playing and saving

Choose Play Computer for an offline game against Pikafish, or Two Players for a shared-device game. Casual games allow undo. Timed games use a separate clock for each side. Use the game menu to save and return home; Continue game resumes the active saved game. The app keeps one active game.

## Learning and practice

Learn and practice opens the bundled Chinese Chess Practical Dataset. Browse openings, endgames, tactics, matches, and mating exercises. The dataset includes recorded lines; practice follows the supplied line rather than claiming it is the unique best continuation.

## Appearance and language

Settings offers Classic, Tournament, and Calm themes, English and Chinese languages, piece labels, coordinates, sound, haptics, and move confirmation. Sound follows the device’s silent-mode setting.

## Privacy and deleting data

Gameplay works offline. Saved games, learning progress, and settings stay on your device. Delete App in iOS Settings removes local app data; Offload App preserves it. Device backups and records you have shared are managed separately. Read the [privacy policy](privacy-policy.md).

## Source and licenses

[Source code and build instructions](https://github.com/frankmanzhu/xiangqi-mobile). License notices are available in Settings → Open-source and content licenses. New games use the pinned Pikafish Computer Rule for repetition, checking, chasing, and draws.
